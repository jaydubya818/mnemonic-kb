# Tech stack

Single-page version-locked summary derived from package.json files. AI sessions can skim this instead of grepping eight package.jsons.

## Runtime

- **Node.js** >= 20
- **TypeScript** ~5.4 (strict mode, `noUncheckedIndexedAccess`)
- **pnpm** workspaces, v9

## Packages and apps

| Package | Role | Key deps |
|---|---|---|
| `@mnemonic/schemas` | Zod schemas | `zod` |
| `@mnemonic/core` | CRUD, filing, vaultWriter, page CRUD | `zod`, `yaml`, `ulid` |
| `@mnemonic/retrieval` | JSON index, ranking, context pack | `zod` |
| `@mnemonic/connectors` | Agentic-KB import/export (stubs) | — |
| `@mnemonic/agent-adapters` | Hermes/Pi adapter types + stubs | — |
| `@mnemonic/cli` (app) | `mnemonic` CLI | core + retrieval + schemas, `yaml` |
| `@mnemonic/mcp-server` (app) | MCP stdio server | `@modelcontextprotocol/sdk`, core + retrieval |
| `@mnemonic/wiki` (app) | Hono read-only wiki | `hono`, `@hono/node-server`, `marked` |

## Build / test

- **tsup** ~8 — per-package ESM build with .d.ts.
- **tsx** ~4 — dev runner for the CLI / wiki / MCP server (no separate compile step needed in dev).
- **Vitest** ~1.5 — test runner. Path aliases in `vitest.config.ts` resolve workspace packages from source so tests don't require a build.

## Storage

- Markdown files (frontmatter + body) — source of truth, on disk, in the user's vault.
- JSON index at `<vault>/.mnemonic/index.json` — generated; `gitignored` if vault is a git repo.
- `<vault>/.mnemonic/.skills-index.json` — generated by `check-resolvable`.

## Excluded by design

- No SQLite, no embeddings, no vector DB in v0.1.
- No HTTP framework other than Hono for the wiki (no Express, no Next.js).
- No React, no client-side bundling.
- No telemetry, no auth, no cloud sync.
- No PostgreSQL, no Redis, no any-DB.

## Conventions

- ESM only (`"type": "module"` everywhere).
- Strict TypeScript. `noUncheckedIndexedAccess: true`.
- Path imports use `.js` extension in source (TS+ESM convention) — required for emitted output.
- Workspace internal imports use `@mnemonic/<pkg>` aliases; `vitest.config.ts` mirrors.

## Known build quirks

- pnpm `--package-import-method copy` is needed on filesystems that don't support hardlinks (e.g. some VM mounts).
- `TMPDIR` should point at a real filesystem with space if the default `/tmp` is on a small mount.
