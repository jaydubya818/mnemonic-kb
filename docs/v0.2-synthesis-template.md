# v0.2 design synthesis (template)

> **Copy this file to `v0.2-design.md` when you have ≥20 captured friction notes. Fill in based only on observed evidence — no imagined features.**

## How to use

1. Run: `mn search "v0.2" --limit 50` and `mn search "Bug"`, `mn search "Friction"`, `mn search "Feature request"`.
2. For each note, paste the title + path into the appropriate bucket below.
3. Cluster duplicates — notes describing the same root cause get merged with `[merged: <id1>, <id2>]`.
4. Score each cluster by **count** (how many notes), **severity** (blocking / friction / nice-to-have), and **fix cost** (S/M/L).
5. Re-rank the priorities at the bottom based on the scoring, not on `docs/dogfood-log.md` §10. **The point of synthesis is that the priorities can change.**
